# Afficionado-Product-Analytics
📊 Afficionado Product Analytics
Afficionado Product Analytics is a data-driven project that explores product performance in a beverage retail environment. The analysis uses SQL queries to uncover insights about sales, revenue, and customer preferences, helping businesses make smarter decisions about pricing, promotions, and inventory.
Key highlights of the project include:
- Top-selling vs least-selling products – Identifying customer favorites and underperformers.
- High-volume but low-revenue items – Spotting products that sell a lot but don’t earn much.
- High-priced but low-sales items – Detecting expensive products that customers rarely buy.
- Overcrowded categories – Finding menu sections with too many variants that slow service.
- Revenue leaders – Highlighting products that generate the most money.
- Popularity vs profitability – Comparing customer demand with actual profit contribution.
This project demonstrates how SQL-based analytics can transform raw transaction data into actionable business insights. It is designed to showcase practical problem-solving, clear reporting, and business storytelling — making it a strong portfolio piece for data analytics.
